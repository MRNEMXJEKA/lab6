# Практична робота №6

## Основи JavaScript: змінні, умови, цикли, функції

### Формат
Комп'ютерний практикум

### Мета роботи
Зробити перші кроки в JavaScript: оголосити змінні (let/const), попрацювати з базовими типами даних, написати умовні конструкції та цикли, оголосити функції (зокрема стрілкові), підключити зовнішній файл `script.js` до HTML-сторінки застосунку з практикумів 1-5 і перевірити результат через консоль браузера.

### Варіант завдання
**Варіант 7 — Список бажань (Wishlist)**

- **Дані:** масив бажань `[{title, price, priority}]`.
- **Цикл:** `for` підсумовує загальну вартість усіх бажань.
- **Умова:** позначити бажання з `priority === 'високий'`.
- **Функція:** `const withinBudget = (price, budget) => price <= budget`.

### Хід роботи

**Крок 1. Створення script.js**
Поруч з `index.html` створено файл `script.js`.

**Крок 2. Підключення файлу до сторінки**
У `<head>` додано тег `<script src="script.js" defer></script>`. Атрибут `defer` завантажує скрипт паралельно зі сторінкою, а виконує його після побудови DOM.

**Крок 3. Перевірка підключення**
Першим рядком скрипта виводиться `console.log('script.js підключено')`. Повідомлення з'являється у вкладці DevTools → Console після завантаження сторінки. Щоб прибрати з консолі помилку 404 для `favicon.ico`, у `<head>` додано `<link rel="icon" href="data:," />`.

**Крок 4. Оголошення даних**
Через `const` оголошено масив `wishes` з об'єктів з полями `title` (рядок), `price` (число) та `priority` (рядок: `'високий'`, `'середній'`, `'низький'`).

**Крок 5. Обробка даних циклом**
Функція `calculateTotal(items)` підсумовує ціни всіх бажань класичним циклом `for`. Накопичувач суми оголошено через `let`. У консоль виводяться кількість бажань (`wishes.length`) і загальна вартість, для форматування використано шаблонні рядки.

**Крок 6. Умовна класифікація**
Функція `markHighPriority(items)` перебирає масив циклом `for...of`. За допомогою `if/else` зі строгим порівнянням `wish.priority === 'високий'` вона позначає бажання з високим пріоритетом зірочкою ⭐.

**Крок 7. Стрілкова функція**
Оголошено стрілкову функцію `withinBudget(price, budget)`, яка повертає `true` або `false`. Її викликано для кожного бажання з бюджетом 5000 грн. Результат («вкладається» чи «не вкладається») обрано потрійним оператором.

**Крок 8. Перевірка відсутності помилок**
У вкладці Console немає червоних записів про помилки, весь вивід відповідає очікуваному.

**Крок 9. Коментування коду**
Над кожною функцією (`calculateTotal`, `markHighPriority`, `withinBudget`) додано короткий коментар `//` з поясненням, що вона робить.

**Крок 10. Збереження змін**
Зміни зафіксовано в Git комітом з описовим повідомленням.
```
git add .
git commit -m "Основи JavaScript: змінні, умови, цикли, функції"
git push
```

### Висновок
У результаті виконання практичної роботи до сторінки застосунку «Список бажань» підключено зовнішній файл `script.js` з атрибутом `defer`, роботу скрипта перевірено через консоль браузера. На практиці використано змінні `const` і `let`, базові типи даних і шаблонні рядки. Дані варіанту оформлено як масив об'єктів, загальну вартість бажань підраховано циклом `for`. Бажання з високим пріоритетом позначено умовою `if/else` зі строгим порівнянням `===`. Також написано стрілкову функцію `withinBudget` для перевірки, чи вкладається ціна в бюджет. Усі результати виведено в консоль без помилок, а зміни збережено в Git.
